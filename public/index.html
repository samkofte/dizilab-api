📚 Dizilab API Dökümantasyonu

Web hostinglerinde (PHP veya Node.js) tek tıkla çalışır. Tüm şifrelenmiş oyuncuları otomatik çözer.

GET /api/all

Son bölümler, diziler ve filmlerin tamamını tek seferde döner.

curl "http://localhost:5050/api/all"

GET /api/stream?url={bolum_veya_film_linki}

İlgili içeriğin tüm oynatıcılarını (Embed + Çözülen HLS Master M3U8) ve altyazılarını döner.

curl "http://localhost:5050/api/stream?url=https://dizilab.to/bolum/mobland-2-sezon-5-bolum/"
